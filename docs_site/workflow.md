# Flux de treball recomanat

## Sequencia recomanada

1. Carrega tots els CSV de trimestres disponibles.
2. Revisa advertencies i metadades detectades.
3. Ajusta etiquetes de trimestre si cal.
4. Selecciona el trimestre de referencia.
5. Analitza primer la vista Grup.
6. Continua amb Materia i Alumne per identificar casos concrets.
7. Usa Comparador per detectar tendencies.
8. Exporta el CSV consolidat per compartir resultats.

## Checklist operatiu

- Les etiquetes T1, T2, T3 son uniques.
- El trimestre actiu es el correcte abans de concloure resultats.
- Els comentaris rellevants han quedat guardats.
- L'exportacio final s'ha validat amb una revisio rapida.

!!! tip "Ritme de treball"
	Passa de visio global a detall individual. Evita començar directament per alumne sense context de grup.
