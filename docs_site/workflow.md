# Flux de treball recomanat

1. Carrega tots els CSV de trimestres disponibles.
2. Revisa advertencies de compatibilitat de versions.
3. Ajusta etiquetes de trimestre si cal.
4. Analitza primer la vista Grup.
5. Continua amb Materia i Alumne per identificar casos concrets.
6. Usa Comparador per detectar tendencies.
7. Exporta el CSV consolidat del trimestre per compartir resultats.
