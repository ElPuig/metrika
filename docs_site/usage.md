# Us de l'eina

## 1. Carrega de fitxers

- Arrossega un o mes fitxers CSV d'actes.
- Verifica que el trimestre detectat es correcte.

## 2. Seleccio de trimestre

- Usa el selector per triar el trimestre actiu.
- Les vistes principals sempre mostren dades del trimestre seleccionat.

## 3. Consulta de vistes

- Grup: estadistiques globals i distribucio de resultats.
- Materia: detall per assignatura.
- Alumne: seguiment individual.
- Comparador: evolucio entre trimestres.
- Exportacio: CSV consolidat del trimestre.

## 4. Comentaris

Des de la barra lateral pots gestionar comentaris de grup, materia, alumne i sessio.
