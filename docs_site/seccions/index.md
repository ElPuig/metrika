# Seccions de l'eina

Aquesta part organitza la documentacio per pestanya funcional de Metrika.

## Com llegir aquestes pagines

Cada seccio inclou:

- Una explicacio breu de la informacio global del tab.
- El detall de cada bloc o visualitzacio principal.
- Captures de pantalla actualitzades quan estan disponibles.
- Explicacio textual quan una captura es opcional o no aplica.

## Navegacio per seccions

- Grup: visio global del rendiment del grup.
- Materia: analisi per assignatura.
- Alumne: seguiment individual i context de l'alumne.
- Comparador: evolucio entre trimestres.
- Exportacio: resum i sortida del trimestre seleccionat.
