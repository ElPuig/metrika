# Introduccio tecnica

Aquesta seccio esta pensada per persones que mantenen Metrika.

## Que hi trobaras

- Com mantenir la documentacio de MkDocs.
- Com automatitzar captures de la UI de Metrika.
- Bones practiques per actualitzar la guia d'usuari sense perdre enfocament funcional.

## Objectiu

La seccio principal de la documentacio ha d'estar orientada a usuaris finals.
Aquesta seccio tecnica concentra la part operativa de desenvolupament.

## Publicacio de docs

La publicacio de la documentacio es fa amb GitHub Actions en push a la branca `dev`.
