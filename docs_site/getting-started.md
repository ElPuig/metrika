# Posada en marxa

Aquesta pagina et guia en menys de 5 minuts per obrir Metrika i començar a analitzar dades reals.

## 1. Engega l'aplicacio

```bash
streamlit run app.py
```

Obre el navegador a http://localhost:8501.

## 2. Carrega fitxers CSV

- Arrossega un o mes fitxers CSV d'actes.
- Espera que Metrika mostri els fitxers detectats.

## 3. Ajusta el trimestre actiu

- Revisa les etiquetes T1, T2, T3.
- Si cal, ajusta-les manualment per mantenir una comparacio correcta.
- Selecciona el trimestre que vols analitzar a les vistes principals.

## 4. Recorregut minim recomanat

1. Grup: visio general de resultats i riscos.
2. Materia: analisi per assignatura.
3. Alumne: seguiment individual i observacions.
4. Comparador: evolucio entre trimestres.
5. Exportacio: descarrega CSV consolidat.

## 5. Guarda comentaris

Des de la barra lateral pots afegir, exportar i importar comentaris de seguiment.

!!! tip "Consell"
    Comenca sempre per la pestanya Grup i baixa al detall nomes quan detectis desviacions.
