# Resolucio de problemes

## No es carrega cap estudiant

- Verifica format i codificacio del CSV.
- Comprova que els fitxers seleccionats son correctes.

## El trimestre no es detecta be

- Revisa el nom i metadades del fitxer.
- Ajusta manualment l'etiqueta del trimestre a l'app.

## Error en executar mkdocs

- Assegura't que `mkdocs` i `mkdocs-material` estan instal.lats.
- Torna a executar: `pip install -r requirements.txt`.

## Error en visualitzacions

- Recarrega l'aplicacio.
- Torna a pujar els fitxers.
- Revisa missatges d'error a pantalla.
